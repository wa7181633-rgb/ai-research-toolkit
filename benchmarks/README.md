# Benchmarks & Evaluation Recipes

This folder will contain ready-to-run evaluation scripts and standard recipes for:

- Math reasoning (GSM8K, MATH, etc.)
- Code generation / execution accuracy
- Instruction following
- Latency & throughput measurements under vLLM

Start by measuring both **quality** and **efficiency**. A model that is 2% better but 3× slower is often not a win for real systems.
