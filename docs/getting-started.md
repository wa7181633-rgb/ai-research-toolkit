# Getting Started

1. Clone the repo
2. Install the core stack:

```bash
pip install unsloth vllm transformer-lens trl peft datasets
```

3. Explore the folders in this order:
   - `prompts/` → improve how you talk to models
   - `training/grpo/` → train a small reasoning model
   - `inference/vllm/` → serve it efficiently
   - `interpretability/` → look inside the model

4. Contribute improvements or new recipes via pull requests.
